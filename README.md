# Pulso Academia — Landing Page

A modern and responsive landing page created for **Pulso Academia**, a fictional urban fitness center.

This conceptual project was developed as part of my web development portfolio, with a strong focus on conversion, responsive design, visual identity, interactive elements, and a clear commercial experience.

> **Note:** Pulso Academia is a fictional brand created exclusively for portfolio and demonstration purposes. All prices, addresses, contact information, business details, and other commercial information displayed on the website are fictional.

## Live Demo

[View the live project](https://pulso-landing-page.vercel.app/)

## About the Project

Pulso Academia was designed as a modern urban gym focused on accessibility, convenience, structure, and a straightforward training experience.

The goal was to create a landing page that communicates the gym's offering quickly while maintaining a strong and energetic visual identity.

Unlike a traditional institutional website, this project places greater emphasis on conversion, pricing, facilities, photography, interaction, and clear calls to action.

## Features

- Fully responsive layout
- Mobile navigation
- Interactive image gallery
- Gallery controls and thumbnails
- Accessible FAQ accordion
- Single-plan pricing section
- Gym facilities presentation
- Training modalities
- Opening hours
- Location section
- Conversion-focused calls to action
- Scroll-based interactions
- Subtle animations and microinteractions
- Basic SEO structure
- Open Graph metadata
- Accessibility considerations
- Reduced-motion support

## Single-Plan Concept

Instead of using multiple pricing tiers, Pulso was designed around a simple commercial proposition:

**One plan. Full gym access.**

The fictional offer includes access to the gym facilities through a single membership, making the pricing section easier to understand and keeping the commercial message direct.

## Interactive Gallery

The project includes an interactive gallery developed with JavaScript.

Users can navigate through the gym environment using controls and thumbnails, allowing the facilities to become an important part of the landing page experience.

## Design Approach

The visual identity combines a dark interface with a vibrant lime-green accent to create an energetic and contemporary atmosphere.

The project prioritizes:

- Strong typography
- High contrast
- Fitness photography
- Clear visual hierarchy
- Direct commercial communication
- Strategic calls to action
- Large visual compositions
- Controlled use of accent colors
- Movement and interaction
- Simple navigation

The interface was designed to feel energetic without relying on excessive effects or visual clutter.

## Responsive Design

The landing page was designed to adapt across:

- Desktop
- Notebook
- Tablet
- Smartphone

Layouts, typography, images, gallery controls, navigation, pricing information, and calls to action are reorganized according to the available screen size.

The mobile experience was treated as an important part of the project rather than simply a scaled-down desktop layout.

## Accessibility

The project includes accessibility considerations such as:

- Semantic HTML
- Appropriate heading hierarchy
- Alternative text for relevant images
- Keyboard-accessible navigation
- Visible focus states
- Accessible mobile navigation
- `aria-expanded` states for interactive components
- `prefers-reduced-motion` support
